## Job Search Analytics - Suivi et analyse de ma recherche d’alternance

### Objectifs : 
Construire un système de suivi et d’analyse de ma recherche d’alternance et construire un modèle prédictif pour estimer la probabilité de réponse d’une candidature.

### Technos :
* Python
* Excel
* PowerBI

### Fonctionnalités BI : 
- Suivi du nombre de candidatures
- Taux de réponse favorables
- Taux d'entretien
- Temps moyen de réponse
- Taux de Refus
- Pipeline de recrutement
- Analyse par entreprise et statut

### Prochaine étape :
- Créer un modèle pour estimer la probabilité de réponse d’une candidature.
